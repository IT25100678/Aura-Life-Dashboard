# Bloom — Personal Life & Routine Tracking Dashboard

> **Live Web Application**: [https://it25100678.github.io/Aura-Life-Dashboard/](https://it25100678.github.io/Aura-Life-Dashboard/)

**Bloom** is a client-side personal dashboard web application that lets users track daily status, activities, habits, and view visual monthly reports through a clean, human-centered aesthetic.

Because it utilizes a Local-First Architecture (saving data inside your browser's local storage), it requires no backend server. This means:
* **100% Free Forever**: Requires no paid hosting, database storage, or subscriptions.
* **Complete Privacy**: All tracked logs remain safely on the user's computer; no personal data is uploaded to a remote server.
* **Global Access**: Everyone can access the site link immediately. Individual logs are stored in each user's own browser.

---

## Key Features

* **Customizable Daily Habits Tracker**: Add custom daily habits or delete unwanted entries with real-time completion status.
* **Daily Focus Priorities**: Pin daily task priorities with automated daily resets.
* **Dynamic Theme Engine**: Light Mode & Midnight Dark Mode support alongside 5 customizable accent color schemes (*Clay, Emerald, Rose, Cyan, Amber*).
* **Month-by-Month Calendar Grid**: Interactive monthly routine timelines with theme-coded completion highlights.
* **Installable PWA App Support**: Progressive Web App integration for iOS, Android, and Desktop featuring a Welcome Splash Screen.
* **Privacy-First Architecture**: Client-side state management using browser `localStorage`.

## How to Run and View the Website Locally

You can run this project on your computer without installing any external compilers:

1. **Download the Repository**: Download or clone this project folder to your local machine.
2. **Open in Browser**: Double-click `index.html` to launch it in Chrome, Safari, Edge, or Firefox.
3. **Edit Code**: Open VS Code (Visual Studio Code), click *File > Open Folder*, and select the project directory:
   * Modify layout structure inside `index.html`.
   * Edit typography, colors, and themes inside `styles.css`.
   * Adjust default behaviors or habit lists inside `app.js`.

## How to Host on GitHub Pages (Step-by-Step Guide)

GitHub Pages allows static web applications to be hosted for free with a custom URL.

### Step 1: Create a GitHub Repository
1. Log in to [GitHub](https://github.com/).
2. Click the **New** button (or *Create Repository*) on the top dashboard.
3. Name your repository: `Aura-Life-Dashboard`.
4. Set visibility to **Public** (required for free GitHub Pages hosting).
5. Click **Create repository**.

### Step 2: Upload Your Files
1. On the repository page, click **uploading an existing file** near the top.
2. Select and upload your project files:
   * `index.html`
   * `styles.css`
   * `app.js`
   * `manifest.json`
   * `sw.js`
   * `bloom_icon.png`
   * `README.md`
3. Click the **Commit changes** button.

### Step 3: Enable GitHub Pages
1. Go to your repository's **Settings** tab.
2. On the left sidebar menu, click **Pages**.
3. Under *Build and deployment > Branch*: Change the dropdown from *None* to **`main`**.
4. Click **Save**.

### Step 4: Access Your Application
1. Wait 30 to 60 seconds and refresh the Pages screen.
2. Access the active URL: [https://it25100678.github.io/Aura-Life-Dashboard/](https://it25100678.github.io/Aura-Life-Dashboard/)
